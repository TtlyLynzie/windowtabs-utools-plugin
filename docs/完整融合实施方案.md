# WindowTabs 完整融合实施方案

目标：原版 ss_2026.11.06 的八个有效设置页面全部在 uTools 内使用。普通用户不安装另一个软件，不接触协议、进程、JSON。Windows 原生组件继续承担窗口管理。

## 信息架构
首页、应用与分组、标签外观、操作习惯、工作区、设置与帮助。全局设置搜索；高级设置折叠但不删除。八个原版页面对应应用、外观、颜色、鼠标、通用、快捷键、工作区、数据维护。旧授权页未被原版启用，不迁移。

## 操作与数据契约
每项设置具有稳定路径、中文名称、类型、范围、选项和来源。界面从原生组件读取有效值；读取失败不呈现可保存的默认值。编辑保留草稿，按变更字段提交，保存前检测原始值冲突，原生线程内校验、保存、回读；失败保留草稿。未识别字段保留。保存配置与实际快捷键注册、工作区恢复结果分别表达。

原生接口 settingsSnapshot/settingsApply、applications/applicationUpdate/windowUpdate、workspaceCapture/workspaceRestore/workspaceRestoreStatus、storageInfo/storageTransfer、setEnabled。旧 hello/getConfig 继续兼容；新增能力以 integrated-settings-v1 标识。没有该能力的后台只显示更新提示，不显示可用的完整设置。

## 页面行为
- 首页：开启/停用功能，关闭面板继续运行。帮助中的停止后台与停用功能分开。
- 应用：运行与已配置应用、启用标签、同应用分组、跨应用分类 1–10、单窗口启用、清除规则。
- 外观：四边独立配置、形状、尺寸、位置、隐藏行为；15 种状态颜色、原版预设、自定义主题保存/改名/排序/删除/导入导出；示意预览不冒充真实桌面效果。
- 操作：按钮显示、鼠标悬停、拖动吸附、预览；Ctrl/Alt 数字模式与12项自定义快捷键。录入按键而非编码。
- 工作区：当前/全部桌面捕获、命名、窗口匹配与标签名称编辑、删除组/窗口/工作区、恢复并等待完成。只整理原版能够匹配的窗口，不承诺启动未打开的软件。
- 数据：原有配置保留；显式备份/导入；配置位置切换需确认并展示影响。诊断报告默认脱敏。

## 后台与更新
插件模式不预加载原版设置、不创建托盘。启动参数写入本插件的启动快捷方式，保持插件模式。退出面板不停止原生组件；退出 uTools 后后台继续工作，帮助中提供明确关闭入口。卸载前关闭功能并取消开机启动；宿主未提供可靠卸载通知时不承诺自动清理。

## 发布门槛
新补丁编译并通过 Windows 真客户端测试前不得替换 dist/market。校验补丁身份、SHA256、新能力、真实设置修改/回读/恢复、冲突拒绝和非法值拒绝；应用/工作区必须进行交互桌面验收。不能把通过连接测试写成全部功能验收。每次上游更新重新核对字段清单和八页操作覆盖，未完成项不得标为完整支持。

发布使用三项绑定：exe 的 SHA-256、设置字段表的 SHA-256、Windows 运行时测试证明。构建先测试后生成市场目录；候选目录全部通过才替换现有 `dist/market`。核心放入“官方版本 + 补丁编号”的唯一目录，避免覆盖 Windows 正在使用的文件。市场目录使用白名单，只保留一个核心和运行必需文件。

## 可恢复性
实施前备份源码；保留现有可发布目录。新源代码与当前旧二进制明确分离。导入前自动备份；后台保存失败必须报告，不能将默认值写回损坏配置。
